# Project Templates (Boilerplates)

This directory contains standardized project templates and boilerplates for various technology stacks. Developers must use these templates when creating a new microservice or application to ensure architectural consistency across all 100+ repositories.

---

## 🛠️ Available Templates

1. **`nodejs-express/`**:
    * A production-ready boilerplate for Node.js using Express.js.
    * Includes structured error handling, environment configuration, logging middleware, and standard folder organization (Controllers, Services, Routes).

2. **`python-fastapi/`**:
    * A high-performance async boilerplate using FastAPI.
    * Includes Pydantic models for validation, dependency injection setup, structured logging, and standard project layout.

---

## 🚀 How to Use

1. Clone or copy the desired template directory when initializing a new repository.
2. Update the `package.json` or `pyproject.toml` with your new service name.
3. Follow the internal folder structure provided in the template for your business logic.
